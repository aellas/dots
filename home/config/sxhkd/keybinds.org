| Focus2 | Focus swap by offset from left/right/up/down | Super+Shift + {Left,Right,Up,Down} / H/J/K/L | bspc ... -s east/west ... |
| F3 | Focus previous/next node in current layout (Super+C, shift+c) | Super+{_shift_ +}{C,c} | bspc ... -f next/prev.local |
| G1 | Desktop focus: prev/Next | Super + {_Left,_Right_|Shift+_Left,Shift+_Right} | bspc desktop -f {prev,next}.local |
| H1 | Focus older/deeper node (Super+O) / newer (Super+I) | Super+{_,shift_+}{O,o,I,i} | bspc ... -h off; bspc node older/newer -f; bspc wm -h on |

# Notes:
- **Focus swap** means: focus *and* move to.
- **O/I, O/o, I/i**: Swap *older, deeper, or newer* focused nodes.
