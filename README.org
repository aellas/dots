** Setup 
- *Distro*: Fedora
- *Package Manager*: Nix
- *Window Manager*: BSPWM
- *Editor*: Doom Emacs
- *Terminal Emulator*: ST
- *Shell*: Zsh
- *File Manager*: Dirvish

** Prerequisites
- Nix must be installed and configured.
- Flakes and Home Manager must be enabled on Fedora.
